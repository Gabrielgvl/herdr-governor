# Protected-path policy (guardrails plan section 3). Single source consumed by
# agent-gate.sh, check-protected-diff.sh, check-lint-integrity.sh, docs/guardrails.md.
# Format: <mode><TAB><pattern>[<TAB>!]   patterns are repo-relative globs (** = subtree).
#   hard        always protected: gate denies writes; diff gate fails on change
#   conditional protected once the path exists
#   section     diff gate applies Cargo.toml section rules R4/R4b/R5
#   report      agent-writable: changes listed, not blocked
#   !           required: must exist and be non-empty (integrity rule I1)
# Matching is by suffix: `tests/support/**` already covers every member's
# `*/tests/support/**` (the (?:^|/) anchor), so per-member dirs need no `**/`
# prefix — the bare forms below also cover a root-level dir if one appears.
